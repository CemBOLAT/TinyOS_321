| **Address Range** | **Data Segment** | **Instruction Segment** | **Explanation**                                |
| ----------------- | ---------------- | ----------------------- | ---------------------------------------------- |

| `2000 - 2999`     | Thread #2 data   | Thread #2 instructions  |                                                |
| `3000 - 3999`     | Thread #3 data   | Thread #3 instructions  |                                                |
| `4000 - 4999`     | Thread #4 data   | Thread #4 instructions  |                                                |
| `5000 - 5999`     | Thread #5 data   | Thread #5 instructions  |                                                |
| `6000 - 6999`     | Thread #6 data   | Thread #6 instructions  |                                                |
| `7000 - 7999`     | Thread #7 data   | Thread #7 instructions  |                                                |
| `8000 - 8999`     | Thread #8 data   | Thread #8 instructions  |                                                |
| `9000 - 9999`     | Thread #9 data   | Thread #9 instructions  |                                                |
| `10000 - 10999`   | Thread #10 data  | Thread #10 instructions |                                                |
